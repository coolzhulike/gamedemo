## 安全恢复到新目录

恢复只需要 **Python 3.9 或更新版本的标准库**，不需要 Blender、Godot 或 pip 安装。
Blender/Godot 仅在恢复完成后打开、编辑或原生复核模型时才需要。

1. 将本目录的 restore_delivery.py 保存到一个单独的工具目录。
2. 在该工具目录打开终端。选择一个**不存在或全新的空恢复目录**，不要指向现有游戏工程。
3. 运行：

    python .\restore_delivery.py --output .\restored_character_review_01

脚本默认从上述 review 分支下载 MANIFEST.json 和分卷，下载缓存放在脚本旁的
review_01_downloads，与恢复输出分开。完整发布会同时包含清单与
delivery.zip.part001 等连续分卷；它们由封包环节生成。

脚本会校验每卷长度与 SHA256、重组 ZIP 的长度与 SHA256、ZIP 成员 CRC，
以及每个恢复文件的长度与 SHA256。ZIP 文件集必须与清单严格一致。
检查全部文件内容后才开始恢复，拒绝路径穿越、Windows 路径别名/设备名/ADS、
重复成员、链接及目标目录中的 symlink/junction/reparse 点。
已存在且内容完全相同的文件跳过，**不同内容的现有文件拒绝覆盖**；不删除用户文件。

若下载或磁盘写入中断，脚本会保留现场并报错，不会宣称成功。可为重试另选两个新目录：

    python .\restore_delivery.py --cache .\review_downloads_retry --output .\review_restored_retry

恢复成功后阅读 restored_character_review_01/DELIVERY_REPORT.md，再打开
restored_character_review_01/review/index.html。优先按 1x 正常速度查看完整视频，
结合缺陷状态和对应源文件/视频 SHA；不能用静帧、抽帧数量或完整性校验替代视觉验收。
