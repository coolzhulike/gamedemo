# 中式无扶手木椅 / Wuxia Wood Chair v1

原创程序化建模，供黑白武侠男女角色的椅坐姿测试及 Godot 场景使用。深胡桃木、微翘搭脑、窄靠背板、简约框线、小铜销，无扶手，给长袖和衣袍留出空间。无外部贴图依赖。

## 文件
- `wuxia_wood_chair.blend`：可编辑部件、非破坏倒角、独立预览摄影棚
- `wuxia_wood_chair.glb`：视觉模型和空节点坐点；不含摄影棚和灯光
- `wuxia_wood_chair.tscn`：Godot 4 即用包装，GLB 视觉 + 13 个简单盒体碰撞 + Marker3D
- `wuxia_wood_chair_preview.png`：实际模型渲染
- `build_chair.py`：可重建资产的 Blender 脚本
- `asset_stats.json`：资产统计

## 真实尺寸与方向
- 单位：米；原点在地面、座面水平中心的正下方
- 座面框顶：0.450 m；座板内嵌面约 0.448 m
- 座面宽 × 深：0.480 × 0.480 m
- 总宽（搭脑）：约 0.532 m；总高：约 0.946 m
- Blender：Z 向上，角色朝向 +Y；椅背位于 -Y
- GLB / Godot：Y 向上，角色朝向 -Z；椅背位于 +Z
- 底脚接地 y=0（Godot）；请保持模型缩放 1

## 坐点约定
- Godot 根节点 `SeatSocket` = (0, 0.450, 0.025)，位于座面接触平面
- `SeatSocket` 不是骨盆骨骼原点。实际坐姿需按角色臀部厚度、髋部骨骼偏移微调，不可直接把 hips 骨放到此点
- 参考脚底目标 `FootTarget_L/R` = (±0.105, 0, -0.360)，只是成人自然椅坐的初始值，按腿长调整
- `GroundOrigin` = (0,0,0)
- 座面 48 cm 是普通椅坐尺度，不能承诺容纳完整盘腿打坐；盘坐应使用地面或另做更宽禅凳

## Godot 使用
把 `.glb` 和 `.tscn` 一起复制到同一资产目录，等待 Godot 导入后实例化 `.tscn`。视觉文件内也带同名空节点，运行时推荐使用包装根部直接提供的 Marker3D。碰撞使用低成本盒体近似，不包含铜销/装饰，不适用于精确离线碰撞检测。该资产不包括角色绑定、动画或完整大世界接入。
