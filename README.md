# 武当大世界 ENV20：已核验环境资产

此批提供有来源证据的 ENV20 场景模型、贴图、材质、地形和道路数据。`project_resources/` 内保持原 Godot 资源相对路径，GLB 为独立可导入模型，包含近中远 LOD。

**此资产子集尚不是可直接运行的完整人物游戏工程。** 正式精模人物、基础动作源以及农舍的再分发来源仍待确认，相关文件没有进入此公开目录。没有用其他角色替代。完整 ENV20 + 待机/走/跑/跳工程已单独保留，待所需权限证据齐备后再补全运行入口。

## 包含

- 武当建筑、亭桥、水车、松竹、草灌、山石等已核验模型与 LOD
- 原地形高度、道路与植被布局，以及 ENV20 局部石土过渡材质
- 原始 PBR 贴图及两张许可为 CC0 的 Poly Haven 岩壁贴图
- 按原路径记录的 SHA-256 清单与排除清单

## 使用与限制

用 Godot 4.6.3 Compatibility 或支持 glTF 2.0 的建模软件导入 GLB。坐标为米制、Y 向上。保持贴图及其相对路径。四份 `world/cache_quadrant_*.scn` 是运行时烘焙地形网格资源，已包含；Godot 的 `.godot/` 导入缓存未包含。

本仓库未为全部原创资产指定新的开源许可证。公开上传不等于将全部资产授予 MIT 或 CC0；仅明确列出的 Poly Haven 文件适用 CC0。详见 `docs/ASSET_ORIGINS.md`。

大文件使用普通 Git 对象存储；没有 Git LFS 指针。所有单文件均低于 100 MiB。
